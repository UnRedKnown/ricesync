# SPECIFIC — machine-specific, opt-in

Nothing in here is installed unless you ask for it:

```sh
./install.sh --specific network            # one section
./install.sh --specific network,hardware   # several
./install.sh --specific all
```

Each section has the same layout:

| path | what |
|---|---|
| `home/` | files that go under `~` |
| `system/` | files that go under `/` |
| `packages-repo.txt` / `packages-aur.txt` | packages for this section (generated by `collect.py`) |
| `services.txt` | systemd units enabled for this section (hand-written) |

## network
VM host bridge and server bits: NetworkManager interface rules, the `enp4s0` bring-up and
Wake-on-LAN units, libvirt/QEMU bridge config (`br_netfilter`, sysctl, `bridge.conf`, the
libvirtd timeout override, a sudoers rule letting your user run `virsh`), sshd, tailscaled, Samba,
ufw rules and resolved/networkd settings.

**Scrubbed:** every IP address, MAC address, hostname, Wi-Fi / connection name and Samba
`netbios name` was replaced by `@IP@`, `@MAC@`, `@HOSTNAME@`, `@NETNAME@` or `@REDACTED@`.
Ports and interface settings are kept. After installing, the installer lists every file that still
contains a placeholder, so you can fill in the values for the new machine.

The interface name `enp4s0` is hard-coded in some of these files. Rename it if the new machine's NIC
is called something else (`ip link`).

## hardware
Peripherals and CPU/GPU-specific tweaks: Keychron udev rules, Logitech M650 hwdb + `logid.cfg`,
input-remapper presets, monitor ICC profiles, intel_lpmd configs (only if you changed them), and the
NVIDIA / CUDA / ROCm / oneAPI packages. CachyOS normally sets up GPU drivers itself (`chwd`), so you
usually only want this section's packages when the new machine has the same GPU.

## services
The backup job: `/etc/backup.conf`, `backup-check.service` and its autostart notifier. (The `backup`
script itself is in the core set under `/usr/local/bin`.) Paths in `backup.conf` are scrubbed if
they pointed at hosts or IPs. Check it before enabling.

## Deliberately left out
Boot setup (Limine, the mkinitcpio wrapper and hook, the boot-menu config), the Mote/Thumby udev
rule and script, Sunshine's config and state (Sunshine is installed as a plain package in the core
set), and anything with credentials: SSH host keys, NetworkManager connections, Samba's private
database, `/etc/hosts`.
